# Agricultural Data Analysis

## Project Overview
This project uses Python to analyze agricultural data from farmers.
The analysis focuses on understanding farming activities, crop production, fertilizer use, farm size, and changes in crop yield.

## Tools Used
* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

## Analysis Performed
* Data cleaning and preparation
* Analysis of crop distribution
* Analysis of farm size and yield
* Analysis of fertilizer use
* Comparison of farming activities
* Data visualization
* Identification of patterns in agricultural production

## Visualizations
The project includes charts showing:
* Percentage of crops grown by farmers
* Relationship between farm size and yield change
* Yield after treatment
* Fertilizer use and yield change

## Project Files
* `farm_analysis.ipynb` — Python analysis notebook
* `jpil_farmers_dataset.csv` — Dataset used for the analysis
* `jpil_farmers_dataset.xlsx` — Excel version of the dataset
* PNG files — Data visualizations

## Conclusion
This project demonstrates how Python can be used to clean, analyze, and visualize agricultural data to identify useful patterns in farming and crop production.
